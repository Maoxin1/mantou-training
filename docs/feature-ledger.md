## TRAIN-07 动作示意（2.4.3，独立预览实机通过）

- T07-M01：三项动作的示意在动作填写页按需展开，涵盖扶大腿家用划船、双哑铃罗马尼亚硬拉、坐姿俯身反向飞鸟。播放由用户主动触发，播完或折叠后回到静态图。系统启用减少动态效果时使用静态图。
- T07-M02：示意离线可用。查看与播放不会写入训练记录、改变动作目标或填写实际动作版本。
- 106 项模块测试、9 组浏览器回归通过。隔离双端演练从 2.4.2 更新到 2.4.3，旧记录、餐照、睡眠和待同步数据均保留。专项浏览器在[独立预览](https://mantou-training-offline-o0moumk5j-mantous-projects-af7e7067.vercel.app/)通过，包含减少动态效果、断网重开及查看前后记录一致。首次部署检查的选择器误选动画画布，修正后重跑通过。
- 用户实机反馈：已有 C 场次时难以找到 B 表，标准俯卧撑只有文字要点。补充 T07-M03，已有 C 场次可直接从「动作示范」浏览三项，浏览不写记录。补充 T07-M04，经「新建场次 · 选表」明确确认 B 时，训练页随即显示 B，原 C 场目标与已填组次保留，取消选择不留场次。先后复现缺入口与确认后仍显示 C，修复后模块测试、浏览器回归和隔离升级通过。
- T07-M03／M04 在[三项修订预览](https://mantou-training-offline-52kdrkkx8-mantous-projects-af7e7067.vercel.app/)专项通过，2026-11-15 本人回复验收通过。
- T07-M05：本人随后确认扩展到三日力量 A／B／C 的全部七个动作。新增标准俯卧撑、扶稳原地分腿蹲、轻哑铃侧平举和短幅死虫式的双图及文字说明。原三项短动画保留。2026-11-15 本人确认[七项独立预览](https://mantou-training-offline-ehsb5kef0-mantous-projects-af7e7067.vercel.app/)通过。

## TRAIN-04 已采纳决策

- T04-D01：用户确认周一 A／周三 B／周五 C，各五个动作、每项两组，另有周末一次羽毛球。30 分钟正课、热身另计。动作表见规范。
- T04-D02：接续既有试行，采用持续阶段与自然周复盘，不重新要求两周试行。
- T04-D03：先预览阶段，再显式启用。旧阶段、旧场次目标和原始反馈保留；仅新阶段使用新动作表。
- T04-D04：沿用 TRAIN-01 的预览／确认语义。进阶条件是用户核对指南，本轮没有自动评分或生成建议的程序。
- T04-D05：最少器械说明折叠展示，不给未知动作自动填公斤数；实际版本、负重、左右次数与恢复仍由本人记录。

没有范围扩张或删除失败验收项。Should 已实现器械／强度说明；Could（自动建议、更多设备指标、提醒）与 Won't（本轮手表自动同步、Logo 重构、照片自动热量和体态诊断）保留，下一轮按目标重新排序。
