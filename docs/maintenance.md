原同步修复 PR #1 已由 PR #3 整合并发布，关闭旧 PR 并保留其验收历史。

2026-10-29 的同步整合提交完成自动回归和隔离账号验收：双设备文字同步、同一天不同字段的离线后合并、餐次照片跨设备读取。正式站的同步状态由用户确认。相同字段冲突、所有移动端浏览器和相机权限没有因此获得完整实机覆盖。

## 发布检查

1. 确认最新主分支内容与待发布提交，处理功能冲突，运行 `npm test`。
2. 涉及存储、同步或照片时，按[贡献说明](../CONTRIBUTING.md)运行适用的隔离集成检查，再记录真实设备结果。
3. 核对 GitHub CI、Vercel 部署提交和生产域名；验证认证配置属于预期环境。
4. 执行适用的线上检查；由用户确认真实账号同步。保留尚未覆盖的场景和回退所需提交信息。
5. 更新变更记录；仅在明确准备版本发布时创建标签和 GitHub Release。
