# TRAIN-05：训练路径与界面减噪

2026-11-11，基线 `5e14419` / 2.4.0。用户采纳 UI 审查建议后执行。新一轮的轻量图标统一不改写 TRAIN-04 当时不做 Logo 重构的历史决定。

## 范围与决策

MoSCoW：Must 为四条常用路径、易读和数据保全；Should 为设置出口整理、浏览器防护、账号隔离证据补充；Could 为现有图标配色统一；Won't 为自动评分、传感器、图表面板、图像热量判断、完整品牌重做和托管认证迁移。术语不直接换算为以下行为约束。

- T05-D01：保留 3 个导航页和数据格式。常用入口显示短文字标签，不以陌生图标替代。
- T05-D02：开始／继续训练进入本场第一个尚未填齐计划组次数的可练动作；单侧动作左右分别检查，不能因填了左侧一组就跳走。都填齐时进入第一个可练动作。这里只定位填写位置，不自动标记训练完成；空白不会填成 0。全部暂停时不创建空场次，提示核对安排。对抗检查据 T05-B03 修订定位细节，未改变数据或训练规则。
- T05-D03：记一餐单独打开；每日反馈仍在记录页。首页旧计划、器械与长说明归入按需展开的计划说明。
- T05-D04：周复盘先展示实际场次、完成情况、逐场记录和缺失项。Markdown、内部标识保留在折叠原文及原导出，不生成未经确认的进阶建议。
- T05-D05：安全测试先补真实应用 API + 签名令牌 + SQL 的隔离验证；本地签发身份不能冒充托管真实邮箱双账号验收。外部开放仍需后者和托管修复确认。
- T05-D06：减噪仍须显示不适提示，并按需保留实际版本、原始疼痛／恢复说明与三餐正文；文字内容和实际食用份量的缺失分别表述。此项是对 R04/R05 的澄清，来自多代理确认的 B04/B05，不扩展自动分析范围。

## 行为规范

| ID | 约束 | 行为／边界 |
| --- | --- | --- |
| T05-R01 | MUST | 开始训练进入动作记录；训练后反馈另有明确入口。新场次保留计划快照，暂停动作不进入常规训练入口 |
| T05-R02 | MUST | 逐组负重、次数／左右次数、余力无需展开即能填写；空白、0、未知含义不变；版本、休息和质量仍可填写 |
| T05-R03 | MUST | 从首页直接记一餐，保留餐次、照片、份量、备注、离线保存与错误提示；不能要求先填睡眠或训练反馈 |
| T05-R04 | MUST | 复盘默认可读，缺失反馈可见；只汇总事实，不将部分训练记为完整，不显示臆造评分；用户文本按文本显示 |
| T05-R05 | MUST | 旧记录、旧阶段、快照、手动确认、ZIP 去重和恢复、离线及同步语义保持；异常／冲突不为减噪隐藏 |
| T05-R06 | MUST | 常用按钮触控区域至少 44×44 CSS px；表单至少 16px，辅助字至少 14px；正文对比度至少 4.5:1；手机／平板及放大文字无关键操作遮挡 |
| T05-R07 | SHOULD | 设置突出每周复盘和完整 ZIP；旧版周报、JSON兼容入口折叠并注明范围；避免仅统计旧记录造成误解 |
| T05-R08 | MUST NOT | 把私人身体资料、照片或账号写入公开默认模板；把模拟账号成功声明为真实托管隔离通过 |
| T05-R09 | SHOULD | HTML 防嵌入、限制脚本来源与对象、禁止 MIME 嗅探并限制来源泄露；兼容认证、照片和离线；API继续不缓存 |
| T05-R10 | MAY | 沿用现有哑铃轮廓统一蓝色；图标同步更新，保持安装和离线入口 |
| T05-R11 | MUST | 服务端身份不来自任意请求头；A不能通过B的账号头、照片ID读取／改写／删除B数据，失败不产生越权写入 |

## 风险与未决项

- 默认空记录、所有动作暂停、历史补记、已有部分组次、HTML字符、手机窄屏、文本放大适用，纳入矩阵。
- 输入编码、睡眠大 ZIP、乱序同步、部分恢复沿用现有回归，不改变处理规范；不因本轮未改动而宣称覆盖所有资源耗尽。
- 动作切换／弹窗关闭只改变视图；实际字段仍按现有保存事务写入。保存失败保留错误与输入，不能伪装成功。
- 安全性质成立前提为正确配置的签名校验和服务端查询；部署者数据库权限、本机可读缓存、明文导出不属于普通账号隔离承诺。
- 阻断外部开放：真实托管 A/B 隔离验收、托管修复证据。暂不阻断本地 UI 迭代：本机缓存清除完整生命周期、生产配额和限流策略，作为后续任务保留。
- 手机／平板真实单手操作及系统字体放大待本人体验；自动浏览器证据不能替代。
