# mantou · 训练卡

> 2.0 邮箱同步开发版：账号、云端保存与离线补传见 [ACCOUNT-SYNC.md](ACCOUNT-SYNC.md)。下方私有站点和仅本机存储描述属于1.x旧入口；2.0需要部署到Vercel并配置服务端数据库后才能使用云端同步。

手机与平板使用的轻量训练 PWA：查看计划、按需记录单个动作、两次进阶验证、临时减量、调整撤销，以及 Obsidian Markdown 周报和完整备份。

## 在线使用

固定入口：<https://mantou-training-journal.upbeatghost9.chatgpt.site>

站点为私有访问，需要获授权的同一账户。GitHub 保存源码，不保存你的实际训练记录。

## 添加到平板桌面

- **iPad**：用 Safari 打开固定入口并登录 → 分享 → 添加到主屏幕；如有“作为网页 App 打开”，保持开启。
- **Android 平板**：用 Chrome／Edge 打开入口 → 浏览器菜单 → 安装应用／添加到主屏幕，或使用网页“导出与备份”中的安装按钮。
- 首次联网打开，等待“离线训练卡已就绪”，再离线使用。应用代码更新时可在“导出与备份”检查更新并手动应用，避免训练中刷新。
- 桌面 PWA 与浏览器可能使用不同存储。已有记录先下载完整 JSON 备份；进入桌面应用后若无原记录，再导入恢复。

## 数据与调整

记录保存在当前设备的 `localStorage`，无后台数据库、无跨设备自动同步。周报用于阅读；完整 JSON 用于恢复。每周导出，换设备或清除浏览器数据前先备份。

没有新记录就保持当前计划。只有开启某个动作的验证后，连续两次可比训练达标、动作规范且恢复正常才推进。未配置可用下一档时不会凭空增加阻力，组数和训练天数不会自动增加。疼痛反馈暂停该动作自动推进。

本项目不提供体型预测或诊断，不承诺参考图可达。

## 本地运行

Node.js 22 或以上；没有外部运行依赖。

```sh
npm start
# http://127.0.0.1:4173
npm test
```

部署时直接提供 `dist/` 静态目录；PWA 需要 HTTPS（localhost 开发除外）。当前应用部署在域名根路径，manifest 和 Service Worker 的路径按根目录配置。不要直接双击 HTML 文件使用。

## 文件

- `dist/engine.mjs`：训练与数据规则。
- `dist/app.mjs`、`style.css`：交互界面。
- `dist/manifest.webmanifest`、`pwa.mjs`、`sw.js`、`icons/`：安装、更新与离线外壳。
- `tests/`：训练规则、备份与 PWA 检查。
- `.github/workflows/test.yml`：推送后运行 Node 测试。
- `.openai/hosting.json`：现有私有站点的部署标识，不包含密钥。

Service Worker 只缓存同源白名单中的静态应用外壳，不缓存登录页、外部请求或实际训练数据。联网时尊重站点登录响应，离线使用本设备已准备好的外壳。移除该设备访问时，需同时处理其本地缓存与记录。

更新部署复用当前站点和网址，不清空训练数据；修改数据格式前应提供迁移并先备份。不提交个人导出、凭据、令牌或浏览器配置。
